## 三、后端 API 改动

### 3.1 `GET /api/alerts` — 新增查询参数

| 参数 | 类型 | 说明 | 现有 |
|------|------|------|:----:|
| `severity` | string | 严重度筛选 | ✅ |
| `status` | string | 状态筛选 | ✅ |
| `host_id` | int | 主机 ID | ✅ |
| **`date_from`** | **string(ISO)** | **开始时间** | ❌ 新增 |
| **`date_to`** | **string(ISO)** | **结束时间** | ❌ 新增 |
| **`case_id`** | **int** | **案件 ID** | ❌ 新增 |
| `rule_name` | string | 规则名筛选 | ⚠️ 已有但未使用 |
| `search` | string | 全文关键词 | ❌ 新增 |
| `limit` | int | 每页条数 | ✅ |
| `offset` | int | 偏移量 | ✅ |

**修改后的 `Alert.list()` SQL 查询**：

```python
@staticmethod
def list(host_id=None, severity=None, status=None, rule_name=None,
         case_id=None, date_from=None, date_to=None, search=None,
         limit=100, offset=0):
    conditions = ["1=1"]
    params = []
    if host_id:
        conditions.append("host_id=?")
        params.append(host_id)
    if case_id:
        # 通过 hosts 表找到案件下的所有主机
        conditions.append("host_id IN (SELECT id FROM hosts WHERE case_id=?)")
        params.append(case_id)
    if severity:
        conditions.append("severity=?")
        params.append(severity)
    if status:
        conditions.append("status=?")
        params.append(status)
    if rule_name:
        conditions.append("rule_name=?")
        params.append(rule_name)
    if date_from:
        conditions.append("first_seen_at >= ?")
        params.append(date_from)
    if date_to:
        conditions.append("first_seen_at <= ?")
        params.append(date_to)
    if search:
        conditions.append("(title LIKE ? OR detail LIKE ? OR source_process LIKE ?)")
        params.extend([f"%{search}%"] * 3)
    sql = f"SELECT * FROM alerts WHERE {' AND '.join(conditions)} ORDER BY last_seen_at DESC LIMIT ? OFFSET ?"
    params.extend([limit, offset])
    ...
```

### 3.2 新增 `GET /api/cases/with-hosts` — 案件主机级联数据

前端需要案件→主机的级联选择数据，新增一个端点：

```python
@router.get("/cases/with-hosts")
def list_cases_with_hosts(current_user=Depends(get_current_user)):
    """返回案件及下属主机列表，用于级联选择器."""
    with get_connection() as conn:
        cases = conn.execute(
            "SELECT id, name, case_number FROM cases ORDER BY created_at DESC"
        ).fetchall()
        result = []
        for c in cases:
            hosts = conn.execute(
                "SELECT id, hostname, ip_address FROM hosts WHERE case_id=? ORDER BY hostname",
                [c["id"]]
            ).fetchall()
            result.append({
                "value": c["id"],
                "label": f"{c['name']} ({c['case_number'] or 'N/A'})",
                "children": [
                    {"value": h["id"], "label": f"{h['hostname']} ({h['ip_address'] or 'N/A'})"}
                    for h in hosts
                ]
            })
        return {"success": True, "data": result}
```

**交互流程**：

## 五、前端状态管理

在 `AlertCenterView.vue` 中新增筛选状态：

```javascript
// 新增筛选状态
const dateRange = ref(null)        // [Date, Date]
const caseHostValue = ref([])      // [caseId] 或 [caseId, hostId]
const caseHostLabel = ref('')       // 展示用
const caseHostOptions = ref([])    // 级联数据
const searchKeyword = ref('')

// 计算是否有任何筛选激活
const hasAnyFilter = computed(() =>
  filterSeverity.value || filterStatus.value ||
  dateRange.value || caseHostValue.value.length > 0 ||
  searchKeyword.value
)

// 重置全部
function resetAllFilters() {
  filterSeverity.value = ''
  filterStatus.value = ''
  dateRange.value = null
  caseHostValue.value = []
  searchKeyword.value = ''
  fetchData()
}

// 构建查询参数
function buildParams() {
  const params = { limit: 100 }
  if (filterSeverity.value) params.severity = filterSeverity.value
  if (filterStatus.value) params.status = filterStatus.value
  if (dateRange.value) {
    params.date_from = dateRange.value[0].toISOString()
    params.date_to = dateRange.value[1].toISOString()
  }
  if (caseHostValue.value.length === 1) {
    params.case_id = caseHostValue.value[0]
  } else if (caseHostValue.value.length === 2) {
    params.host_id = caseHostValue.value[1]
  }
  if (searchKeyword.value) params.search = searchKeyword.value
  return params
}
```

## 七、交互流程

```
页面加载
  ├── GET /api/alerts → 初始告警列表
  ├── GET /api/alerts/stats/summary → 初始统计
  ├── GET /api/cases/with-hosts → 级联选择器数据
  └── WebSocket 连接 → 实时推送

用户选择日期范围
  → dateRange 更新
  → fetchData() 带上 date_from / date_to
  → 告警列表刷新
  → summary 统计同步更新

用户选择案件→主机
  → caseHostValue 更新
  → 如果只选了案件: 传 case_id
  → 如果选了案件+主机: 传 host_id
  → fetchData()

用户点击已选条件标签的 ×
  → 清除对应的筛选条件
  → fetchData()

用户点击"重置全部"
  → 清除所有筛选条件
  → fetchData()
```
