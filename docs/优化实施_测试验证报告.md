## 四、修复的 Bug

| Bug | 原因 | 修复 |
|-----|------|------|
| `_normalize_path` NT 前缀展开顺序错误 | `\??\` 在第5步才剥离，导致环境变量和 SystemRoot 正则无法匹配 | 移到第1步，并在 NT 前缀后二次清理引号 |
| `rule_engine.evaluate` 中 `UnboundLocalError` | `from datetime import datetime` 在条件分支里，攻击链匹配代码引用 `datetime.now()` 时未绑定 | 移到 evaluate() 顶部无条件执行 |
