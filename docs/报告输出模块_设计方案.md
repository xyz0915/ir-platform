# 报告输出模块 — 应急专家设计方案

> **设计视角**：一线应急响应专家
> **痛点**：案件处理完要写报告，1 份报告平均 2-4 小时
> **目标**：把报告从 2 小时压到 **15 分钟内**，从"自由文本"变成"结构化模板"

---

## 0. 应急专家分析

### 当前痛点

```
案件处理完 → 1 写报告（耗时 2-4 小时）
              2 找现场（要在时间线/告警/进程树/案件之间反复跳）
              3 复制粘贴（数据从各处手抄）
              4 排版（发领导）
              5 失实风险（数据可能有疏漏）
```

### 优秀报告应具备的 7 大要素

| 要素 | 当前能力 | 期望能力 |
|:-----|:--------|:--------|
| 1. **概要** | 无 | 一句话讲清楚"谁、什么时候、做了什么事" |
| 2. **影响范围** | 无 | 哪些资产受影响、业务影响 |
| 3. **时间线** | 散在多处 | 自动生成 KILL CHAIN 风格时间线 |
| 4. **MITRE 战术** | 散在告警 | 战术覆盖图谱 |
| 5. **证据链** | 散在日志 | 关键证据自动收集（截图+原始数据） |
| 6. **建议措施** | 无 | 短期/中期/长期三段式建议 |
| 7. **附件** | 无 | 一键导出 PDF/Word/JSON |

## 3. 核心功能清单

### 3.1 AI 一键生成报告

点击 "🤖 AI 自动生成"：
- 自动选择当前案件的所有告警+时间线
- 调用 LLM 生成 7 段式报告内容
- **15 秒内**返回完整草稿

```
已实现: POST /api/ai/narrate-incident  (时间线部分)
新增: POST /api/ai/generate-report   (完整 7 段)
```

### 3.2 报告模板库

内置 4 种行业标准模板：

| 模板 | 适用场景 | 章节 |
|:-----|:---------|:-----|
| 🚨 应急响应报告 | 安全事件发生后 | 概要+影响+时间线+证据+建议 |
| 🔍 取证简报 | 司法/合规取证 | 物证清单+数据完整性+证据链 |
| 📜 合规审计报告 | 等保/PCI/ISO | 范围+基线+差距+整改清单 |
| 📝 阶段汇报 | 处置进展同步 | 摘要+已完成+进行中+待办+风险 |

### 3.3 多人协作

- 📝 草稿：分析师撰写中
- 👀 待审：分析师完成后转给安全负责人
- ✅ 已发：审核通过，下发
- 📦 归档：超过 90 天自动归档

### 3.4 导出与打印

| 格式 | 用途 |
|:-----|:-----|
| 📄 PDF | 最终交付 |
| 📝 Word | 二次编辑 |
| 📊 JSON | 数据交换/对接 SOC |
| 🔗 只读链接 | 分享给领导，无痕查看 |

## 4. 数据库设计

```sql
-- 报告主表
CREATE TABLE IF NOT EXISTS incident_reports (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    case_id         INTEGER REFERENCES cases(id),
    host_id         INTEGER,
    title           TEXT NOT NULL,
    report_type     TEXT,           -- emergency/forensic/compliance/status
    audience        TEXT,           -- leader/tech/compliance
    status          TEXT,           -- draft/review/published/archived
    summary         TEXT,
    impact_scope    TEXT,           -- JSON: 主机/告警/IOC 统计
    timeline_json   TEXT,           -- JSON: KILL CHAIN
    mitre_cover     TEXT,           -- JSON: ATT&CK 战术覆盖
    evidence_json   TEXT,           -- JSON: 关键证据
    recommendations TEXT,           -- JSON: 三段式建议
    template        TEXT,           -- 模板名
    created_by      INTEGER,
    reviewed_by     INTEGER,
    created_at      TEXT,
    updated_at      TEXT,
    published_at    TEXT
);

-- 报告评论/协作
CREATE TABLE IF NOT EXISTS report_comments (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    report_id       INTEGER REFERENCES incident_reports(id) ON DELETE CASCADE,
    user_id         INTEGER,
    section         TEXT,
    content         TEXT,
    created_at      TEXT
);

-- 报告模板
CREATE TABLE IF NOT EXISTS report_templates (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    name            TEXT,
    description     TEXT,
    sections_json   TEXT,           -- 模板章节定义
    created_at      TEXT
);
```

## 5. API 端点

```
GET    /api/reports                      # 报告列表(分页+筛选)
POST   /api/reports                      # 新建空白报告
GET    /api/reports/{id}                 # 报告详情
PUT    /api/reports/{id}                 # 更新报告
DELETE /api/reports/{id}                 # 删除报告

POST   /api/reports/{id}/submit         # 草稿→待审
POST   /api/reports/{id}/publish        # 待审→已发
POST   /api/reports/{id}/archive        # 已发→归档

POST   /api/reports/generate             # AI 一键生成报告
POST   /api/reports/{id}/comments       # 添加评论
GET    /api/reports/{id}/comments        # 评论列表

GET    /api/reports/{id}/export/pdf      # 导出 PDF
GET    /api/reports/{id}/export/word     # 导出 Word
GET    /api/reports/{id}/export/json     # 导出 JSON
```

## 7. 关键亮点

### 亮点 1：AI 一键生成
- 15 秒从 0 到完整报告
- 分析师只剩"校对"工作（2-4 小时 → 15 分钟）

### 亮点 2：7 段式结构化模板
- 不写自由文本，所有字段预定义
- 保证团队所有报告风格统一

### 亮点 3：自动从案件拉数据
- 时间线、MITRE、证据、影响范围 全部自动
- 避免人工抄写错误

### 亮点 4：多人协作 + 审核流
- 草稿 → 待审 → 已发 状态机
- 评论 + @ 提醒

### 亮点 5：导出与分享
- PDF/Word/JSON 一键导出
- 只读链接分享给领导
