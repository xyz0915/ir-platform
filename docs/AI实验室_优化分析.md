# AI 实验室 — 优化分析报告

## 当前问题诊断

| 功能 | 现状 | 问题 |
|:-----|:-----|:-----|
| 💬 自然语言指挥台 | 输入→JSON 文本展示 | 返回的 JSON 普通用户看不懂，没有可视化卡片/表格 |
| 📊 告警降噪 | 表格展示归并事件 | 归并后缺少"事件聚合视图"、阶段占比、严重度分布 |
| 📖 攻击故事 | 纯文本输出 | 没有锚点导航、阶段高亮、建议 checklist 交互 |
| 🎯 预测预警 | 数字排行表格 | 没有评分雷达图/进度条、无法下钻看到具体扣分项 |
| ✅ 误报管理 | 模式列表表格 | 没有搜索/分类统计、无法区分"已学习"和"已生效" |

---

## 优化要点

### 1. 💬 自然语言指挥台 — 从"查 JSON"到"看面板"

| 优化项 | 说明 |
|:-------|:------|
| 意图类型化展示 | 告警→告警卡片列表（带严重度色标）<br>日志→日志时间线视图<br>主机→主机状态卡片<br>统计→仪表盘小部件 |
| 快速问模板 | "给我看看主机 WEB-SRV-01 的问题" → 自动调 narrate+correlate 两条路 |
| 结果可交互 | 告警卡片可点击跳转到告警中心，主机可跳转详情 |

### 2. 📊 告警降噪 — 从"规则分组列表"到"事件作战图"

| 优化项 | 说明 |
|:-------|:------|
| 事件卡片视图 | 每个事件一个卡片，显示攻击阶段徽章+主机数+告警数+时间窗口 |
| 阶段分布饼图 | ECharts 展示各攻击阶段占比（初始入侵/持久化/外连C2...）|
| 严重度分布 | 事件按严重度分色（红/橙/蓝）|
| 事件详情下钻 | 点击事件显示该事件包含的告警明细列表 |

### 3. 📖 攻击故事 — 从"墙文字"到"攻击报告"

| 优化项 | 说明 |
|:-------|:------|
| 阶段锚点导航 |  阶段: 初始入侵 → 代码执行 → 持久化 → 外连C2  可点击跳转 |
| 时间线可视化 | 每个阶段有彩色徽章 + 时间戳列表 |
| 建议措施 checklist | 🟢 已执行 / ⬜ 待执行 交互式操作 |
| 故事长度调整 | 简短/详细 两种模式 |

### 4. 🎯 预测预警 — 从"数字排行"到"风险驾驶舱"

| 优化项 | 说明 |
|:-------|:------|
| 风险等级进度条 | 每个主机用彩色进度条显示 0-100 分 |
| 评分维度下钻 | 点击评分显示该主机的7维度评分明细(登录失败/严重告警/审计清除...)|
| TOP N 对比 | 前5名对比柱状图 |
| 风险趋势 | 多次评分的趋势折线(需后端存历史) |

### 5. ✅ 误报管理 — 从"列表"到"误报分析台"

| 优化项 | 说明 |
|:-------|:------|
| 命中统计 | 按规则聚合的误报柱状图，一眼看出最吵的规则 |
| 精准搜索 | 规则名+进程+主机 三栏搜索 |
| 误报率指标 | 展示该规则的告警总命中 vs 误报命中比例 |
| 批量清除 | 勾选多条→批量删除 |
