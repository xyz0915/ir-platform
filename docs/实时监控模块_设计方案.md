## 二、Agent 常驻模式（核心改动）

### 2.1 新增 `--daemon` 模式

当前 Agent 是**一次性运行**（采集 → 输出 JSON → 退出）。新增常驻模式：

```bash
# 常驻模式（7×24 实时监控）
python agent.py --daemon
python agent.py --daemon --server http://平台:8000  --token xxxx

# 仍然支持一次性采集（兼容现有流程）
python agent.py
```

### 2.2 常驻生命周期

```
启动 → 采集系统快照（system_info/users/services/startup_items）
  → 注册到平台（POST /api/agents/register）
  → 进入事件循环：
      while True:
        采集增量事件（进程创建/网络连接/文件变更）
        写入 EventRingBuffer
        if buffer.should_flush():
            POST /api/hosts/{host_id}/process-events {events}
            POST /api/hosts/{host_id}/heartbeat {timestamp}
        sleep(1)
  → 收到 SIGTERM/SIGINT：
      POST /api/hosts/{host_id}/disconnect
      flush 剩余事件
      退出
```

### 2.3 增量采集器

| 采集器 | 平台 | 机制 | 频率 |
|--------|:----:|------|:----:|
| **进程事件** | Win | ETW（降级：轮询快照 diff） | 实时 / 5s |
| **进程事件** | Linux | auditd（降级：/proc 轮询） | 实时 / 5s |
| **网络连接** | All | 轮询 netstat/ss | 30s |
| **文件变更** | Win | ReadDirectoryChangesW | 10s |
| **文件变更** | Linux | inotify | 10s |
| **CPU/内存** | All | psutil | 60s |
| **心跳** | All | HTTP POST | 30s |

## 三、实时告警引擎

### 3.1 事件→告警流程

```
Agent 推送事件
    │
    ▼
process_events 端点 → ProcessEventConsumer.ingest() → 落库
    │
    ▼
ProcessEventConsumer.evaluate()
    ├── RuleEngine.evaluate() → 常规规则检测
    ├── 事件速率分析 → 异常暴增检测
    ├── 聚合计数 → 同一类型事件 N 次/分钟
    │
    ▼
命中规则 → 创建实时告警
    ├── severity: critical/high/medium/low
    ├── rule_name: 命中规则名
    ├── source: 触发事件的 PID/进程名
    ├── timestamp: 事件时间
    ├── status: open / acknowledged / resolved / dismissed
    └── metadata: 上下文信息

    │
    ▼
WebSocket 广播 → 前端实时弹出
    │
    ▼
告警写入 alerts 表（持久化，不断重启丢失）
```

### 3.2 告警表 `alerts`

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER PK | 自增 |
| `host_id` | INTEGER FK | 关联主机 |
| `case_id` | INTEGER FK NULL | 关联案件（可选） |
| `rule_name` | TEXT | 命中规则名 |
| `severity` | TEXT | critical/high/medium/low |
| `status` | TEXT | open→acknowledged→resolved→dismissed |
| `title` | TEXT | 告警标题 |
| `detail` | TEXT | 告警详情 JSON（含 PID、进程名、命令行等） |
| `source` | TEXT | 触发源（如 "process:1234"） |
| `count` | INTEGER | 相同告警聚合次数 |
| `first_seen_at` | TEXT | 首次触发时间 |
| `last_seen_at` | TEXT | 最近触发时间 |
| `acknowledged_by` | TEXT | 确认人 |
| `resolved_at` | TEXT | 解决时间 |

### 3.3 告警聚合（关键降噪）

同一规则在同一主机上短时间内反复触发时，**不重复创建告警**，而是聚合：

```python
def create_or_update_alert(host_id, rule_name, severity, title, detail):
    """创建或更新告警（5 分钟内相同告警 → 聚合计数）."""
    recent = db.execute(
        "SELECT id, count FROM alerts WHERE host_id=? AND rule_name=? AND status='open' AND last_seen_at > ?",
        [host_id, rule_name, (datetime.now() - timedelta(minutes=5)).isoformat()]
    ).fetchone()
    
    if recent:
        # 聚合：计数 +1，更新最后触发时间
        db.execute(
            "UPDATE alerts SET count=count+1, last_seen_at=? WHERE id=?",
            [datetime.now().isoformat(), recent["id"]]
        )
        return recent["id"], False  # False = 聚合，非新告警
    else:
        # 新建告警
        ...
        return new_id, True  # True = 新告警
```

## 四、WebSocket 实时推送

### 4.1 使用 FastAPI WebSocket

```python
from fastapi import WebSocket, WebSocketDisconnect

class AlertWebSocketManager:
    """告警 WebSocket 连接管理器."""
    
    def __init__(self):
        self._connections: dict[int, list[WebSocket]] = {}  # user_id → [ws, ...]
    
    async def connect(self, user_id: int, ws: WebSocket):
        await ws.accept()
        self._connections.setdefault(user_id, []).append(ws)
    
    async def broadcast(self, alert: dict):
        """广播告警到所有连接的客户端."""
        for user_id, conns in self._connections.items():
            for ws in conns:
                try:
                    await ws.send_json(alert)
                except Exception:
                    conns.remove(ws)

alert_manager = AlertWebSocketManager()

@router.websocket("/ws/alerts")
async def alert_websocket(websocket: WebSocket):
    user_id = authenticate_ws(websocket)  # Token 认证
    await alert_manager.connect(user_id, websocket)
    try:
        while True:
            await websocket.receive_text()  # 保持连接
    except WebSocketDisconnect:
        alert_manager.disconnect(user_id, websocket)
```

### 4.2 前端 WebSocket 连接

```javascript
// LiveAlertPanel.vue
const ws = new WebSocket(`ws://${location.host}/api/ws/alerts?token=${token}`)

ws.onmessage = (event) => {
    const alert = JSON.parse(event.data)
    if (alert.is_new) {
        // 新告警 → 弹窗 + 声音
        showAlertNotification(alert)
        playAlertSound(alert.severity)
    }
    // 更新告警列表
    alerts.value.unshift(alert)
    if (alerts.value.length > 100) alerts.value.pop()
}
```

## 六、主机在线状态

### 6.1 心跳检测

```python
# Agent 每 30s 发一次心跳
# 后端检测：超过 90s 未收到 → 标记离线
@router.get("/api/hosts/online-status")
def get_online_status():
    """获取所有主机的在线状态."""
    rows = db.execute(
        "SELECT h.id, h.hostname, h.ip_address, "
        "CASE WHEN a.last_heartbeat > ? THEN 'online' ELSE 'offline' END as status "
        "FROM hosts h LEFT JOIN agents a ON h.id = a.host_id",
        [(datetime.now() - timedelta(seconds=90)).isoformat()]
    ).fetchall()
    return [{"id": r[0], "hostname": r[1], "status": r[2]} for r in rows]
```
